Cara memakai

        
    
          
  1. Izinkan lokasi saat diminta browser agar GPS aktif.
    2. 
          
  2. Tekan Lokasi agar peta mengarah ke posisi Anda.
    3. 
          
  3. Berdiri di sudut lahan, tekan Titik GPS. Ulangi di setiap sudut secara berurutan.
    4. 
          
  4. Atau aktifkan Mode jalan lalu kelilingi batas lahan — app merekam banyak titik.
    5. 
          
  5. Tekan Tutup: jika titik > 8, app menyederhanakan ke 8 titik paling mewakili lalu membentuk poligon.
    6. 
          
  6. Isi info lahan, simpan ke daftar, lalu Unduh GeoJSON.
    7. 
          
  7. Pakai Muat GeoJSON untuk membuka kembali file yang sudah diunduh atau dari QGIS/app lain.
    8. 
          
  8. Muat data BSRE menampilkan dataset POLSH BSRE 1119 (1.212 bidang). Ketuk bidang → Edit di Geopatok.
    9. 
          
  9. Setelah BSRE dimuat, pakai kotak Cari ID (atau menu Cari bidang BSRE) untuk menemukan poligon by ID.
    10. 
          
  10. Tandai ID peta: input satu/banyak ID → poligon jadi merah gelap permanen. Input ID yang sama lagi untuk menghapus tanda.
    11. 
          
  11. Locate Red: tombol radar — zoom ke semua tanda merah + sinyal radar. Ketuk lagi untuk mematikan.
    12. 
          
  12. Peta offline: unduh ubin area yang tampil di peta (saat online). Setelah itu app + peta bisa dipakai tanpa internet. Pasang ke layar utama agar SW stabil.
    13. 
          
  13. Ketuk poligon → Set as destination untuk rute dari lokasi GPS Anda ke lahan tersebut (jalan/mobil via OSRM).
    14. 
          
  14. Pasang di Android: buka lewat Chrome (HTTPS) → menu ⋮ → Install app / Tambahkan ke layar utama, atau tombol Pasang di menu aplikasi.
    15. 
        

        
Tips akurasi

        
    
          
  • Gunakan di area terbuka (langit cerah), jauh dari gedung tinggi.
    • 
          
  • Tunggu badge GPS hijau (akurasi bagus) sebelum menambah titik.
    • 
          
  • Mode satelit membantu menyesuaikan batas visual.
    • 
          
  • Berdiri diam 3–5 detik di setiap sudut sebelum merekam titik.
    • 
          
  • Untuk hasil survei formal, verifikasi ulang di lapangan / software GIS.
    • 
        

        
Data tersimpan lokal di perangkat Anda (localStorage). Tidak dikirim ke server.
