Cara memakai

        
    
          
  1. Izinkan lokasi saat diminta browser agar GPS aktif.
    2. 
          
  2. Tekan Lokasi agar peta mengarah ke posisi Anda.
    3. 
          
  3. Berdiri di sudut lahan, tekan Titik GPS. Ulangi di setiap sudut secara berurutan.
    4. 
          
  4. Atau aktifkan Mode jalan lalu kelilingi batas lahan — titik terekam otomatis.
    5. 
          
  5. Minimal 3 titik, lalu tekan Tutup untuk membentuk poligon.
    6. 
          
  6. Isi info lahan, simpan ke daftar, lalu Unduh GeoJSON.
    7. 
        

        
Tips akurasi

        
    
          
  • Gunakan di area terbuka (langit cerah), jauh dari gedung tinggi.
    • 
          
  • Tunggu badge GPS hijau (akurasi bagus) sebelum menambah titik.
    • 
          
  • Mode satelit membantu menyesuaikan batas visual.
    • 
          
  • Berdiri diam 3–5 detik di setiap sudut sebelum merekam titik.
    • 
          
  • Untuk hasil survei formal, verifikasi ulang di lapangan / software GIS.
    • 
        

        
Data tersimpan lokal di perangkat Anda (localStorage). Tidak dikirim ke server.
